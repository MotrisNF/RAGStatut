# Fictional contracts

Made by `tools/generate_contracts.py` to demonstrate MiConvenio. People and companies are invented; the contracts are in Spanish, like the agreements.

`_answer_key.json` holds the planted discrepancies and the limits of each agreement: it is only for evaluating and **must never be sent to the model**. `_active.json` lists the contracts the page offers. Salaries are invented and not checked against the current tables.
